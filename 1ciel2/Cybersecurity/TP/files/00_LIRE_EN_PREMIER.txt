## 🎮 UTILISATION

### Menu principal s'affiche automatiquement :
```
1:Stock 2:Recup
3:Cle   4:Liste
```

### Touche 1 : Stocker un mot de passe
```
1. Appuyer sur 1
2. Saisir le nom du site (ex: FACEBOOK)
   - Appuyer 3 fois sur 2 → F
   - Appuyer 1 fois sur 2 → A
   - etc... (VRAI T9)
3. Appuyer sur # pour valider
4. Saisir le mot de passe
5. Appuyer sur #
6. ✓ LED verte + Bip = Stocké !
```

### Touche 2 : Récupérer un mot de passe
```
1. Appuyer sur 2
2. Saisir le nom du site
3. Appuyer sur #
4. ✓ Affichage du mot de passe pendant 10 secondes
5. LED bleue + Bip
```

### Touche 3 : Changer la clé secrète
```
1. Appuyer sur 3
2. Saisir l'ancienne clé
3. Appuyer sur #
4. Saisir la nouvelle clé
5. Appuyer sur #
6. ✓ Tous les mots de passe sont rechiffrés automatiquement
7. LED jaune + Bip
```

### Touche 4 : Afficher la liste
```
1. Appuyer sur 4
2. Chaque site s'affiche 1.5 secondes
3. Total affiché à la fin
```

### Touches spéciales
```
* (astérisque) → Ajoute un espace directement
# (dièse)      → Valide la saisie complète
A              → Retour au menu
B              → Backspace (effacer dernier caractère)
C              → Clear (effacer tout)
D              → Annuler
```

## 📚 RÉFÉRENCES RAPIDES

### Pins Arduino utilisés
```
Pin 2-9   → Clavier (8 pins)
Pin 10    → Buzzer
Pin 11    → LED jaune
Pin 12    → LED bleue
Pin 13    → LED verte
Pin A4    → LCD SDA (I2C)
Pin A5    → LCD SCL (I2C)
5V, GND   → Alimentation
```

### Affichage LCD
```
Ligne 1 : T9:[a b c] ← Affichage du T9
Ligne 2 : hel_      ← Texte saisi + curseur
```

### Sons du buzzer
```
1000Hz, 200ms  → Confirmation (stockage OK)
1500Hz, 150ms  → Déchiffrement (mot de passe trouvé)
2000Hz, 200ms  → Changement de clé réussi
500Hz, 500ms   → Erreur (mauvaise clé)
```

### LEDs
```
Verte (Pin 13)  → Stockage réussi
Bleue (Pin 12)  → Récupération d'un mot de passe
Jaune (Pin 11)  → Changement de clé réussi
```

## ⚠️ PROBLÈMES COURANTS

### LCD affiche rien
→ Vérifier l'adresse I2C (0x27 ou 0x3F)
→ Consulter DEPANNAGE_RAPIDE.md

### Clavier ne marche pas
→ Vérifier les pins 2-9
→ Consulter DEPANNAGE_RAPIDE.md

### Code ne compile pas
→ Vérifier les bibliothèques Keypad et LiquidCrystal_I2C
→ Consulter DEPANNAGE_RAPIDE.md
