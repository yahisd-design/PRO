   # : Valider
   * : Espace
   A : Menu
   B : Backspace
   C : Clear
   D : Annuler
   0-9 : Saisie T9

🔌 CONFIGURATION MATÉRIEL (RÉSUMÉ)
================================================================================

Clavier 4x4 → Pins 2-9 (8 pins)
LCD I2C → Pins A4, A5 + 5V, GND
LEDs → Pins 11, 12, 13 + résistances 220Ω
Buzzer → Pin 10
